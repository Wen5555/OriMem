# Welcome to OriMem

OriMem maintains this vault; agents such as Claude Code, Codex and DeepSeek Harness search and record here through MCP. Browse and edit it like any Obsidian vault.

## Start here

- Projects: `{projects}` - one page per project; agents update status and next steps after results are confirmed.
- Daily notes: `{daily}` - written each day when the daily summary is on.
- Conversation evidence: `{evidence}` - captured transcripts; evidence only, do not edit the generated transcript region.
- Knowledge: `{knowledge}`; unsorted: `{inbox}`.
- Rules: [[AGENTS]] describes what agents may read and write here.

## Commands

- `orimem doctor`: check the model, hooks, capture and Obsidian.
- `orimem config get layout`: show the folder layout; `orimem config set layout.daily "Journal/Daily"` renames one.
- `orimem open`: open this vault in Obsidian.

You can delete this note; OriMem will not recreate it.
